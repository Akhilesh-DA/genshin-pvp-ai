# Genshin Impact Adaptive PvP AI

An AI-based PvP combat system designed to control teams of Genshin Impact characters in dynamic combat environments.

## Supported PvP Formats

- 1v1
- 2v2
- 3v3
- 4v4

Future extension:

- NvN

## Key Features

- Adaptive PvP decision-making
- Dynamic combat environments
- Team-based strategy
- Opponent behaviour modelling
- Character switching
- Risk-aware decision making
- Environmental effects
- Team synergy
- Long-term strategic planning
